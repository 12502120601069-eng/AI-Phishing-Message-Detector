# AI-Based Phishing Message Detector

## Introduction

This is a beginner-level AI project that predicts whether a message may be phishing or legitimate.

## Features

* Enter a message to check.
* Predicts the message category using Machine Learning.
* Allows checking multiple messages.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Naive Bayes

## How It Works

The program learns from sample messages labelled as phishing or legitimate. When a user enters a new message, the model predicts its category.

## How to Run

Install the required libraries:

`pip install -r requirements.txt`

Run the program:

`python main.py`

## Limitations

The project uses a small sample dataset, so predictions may be incorrect. It is intended for educational purposes only.
